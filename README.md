
## Accounts, payments, tutors
Students and tutors create their own accounts (Create account page). Tutors manage availability, profile and bookings in their dashboard. Payments: see BACKEND.md. Sample tutors are placeholders (marked 'Sample profile'); edit `SEED` in `app.js` or remove them.

## Admin account
Log in at `index.html#login` with the admin email and password above. In Admin, Users tab you can add, edit, suspend/activate, reset the password of, or remove any tutor or student. The Settings tab sets the default hourly rate (tutors do not set their own; Admin can override per tutor) and changes the admin password.
